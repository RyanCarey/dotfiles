# Terminal font & color settings (exported 2026-10-20)

- `Terminal.app/*.terminal` — one file per Terminal.app profile (default: **Basic**). Import via Terminal → Settings → Profiles → ⋯ → Import, or double-click.
- `Terminal.app/com.apple.Terminal.plist` — full Terminal.app preferences (XML).
- `iTerm2/profiles.json` — iTerm2 profiles (Default: Monaco 12) as a Dynamic Profile: copy to `~/Library/Application Support/iTerm2/DynamicProfiles/`.
- `iTerm2/com.googlecode.iterm2.plist` — full iTerm2 preferences (XML); restore with `defaults import com.googlecode.iterm2 <file>` while iTerm2 is closed.
